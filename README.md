🌌 About NOVA AI

NOVA AI is a personal AI assistant project focused on creating a modern, interactive, and user-friendly AI experience.

With a futuristic interface and a full-stack web architecture, NOVA AI aims to bring intelligent conversations and a smooth user experience together in one place.

«💡 Our Vision: Make AI interactions feel natural, accessible, and enjoyable.»

⚙️ Getting Started

1. Clone the repository

git clone https://github.com/ThirusenthilkumarC/Ai-Assistant-.git
cd Ai-Assistant-

2. Install dependencies

Open a terminal in the frontend folder:

cd frontend
npm install

Open another terminal in the backend folder:

cd backend
npm install

3. Configure environment variables

Create the appropriate ".env" file in the backend directory and add the environment variables required by your implementation.

For example:

PORT=5000
GEMINI_API_KEY=your_api_key_here

Use the exact variable names expected by your code. Never commit API keys or secret credentials to GitHub.

4. Start the application

Run the frontend and backend using the scripts defined in their respective "package.json" files.

Typical Vite and Node.js commands may look like:

# Frontend
npm run dev

# Backend
npm run dev

If the configured ports match your local setup:

- Frontend: http://localhost:5173
- Backend API: http://localhost:5000/api

These are local development addresses, not public deployment links.
